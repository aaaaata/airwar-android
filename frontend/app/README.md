##  快速开始

### 环境要求
- Android Studio：Koala Feature Drop 或更高
- AGP 版本：9.1.0
- Gradle 版本：9.0+
- 最低 SDK：API 30

### 导入运行
1. 删除根目录下.idea,build,local.properties文件
2. 用 Android Studio 打开项目根目录
3. 等待 Gradle 同步
4. 连接设备，点击运行
